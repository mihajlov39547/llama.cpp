Quick start: Open preview.html in a browser; use icons.css and <span class="fb-icon fb-icon--friends"></span>.

For self-hosted PNG assets: pip install pillow requests; python extract_png.py. Use icons-local.css afterwards. This script downloads original image sprites when run with internet access.

The provided HTML contains image links, NOT the image bytes, so PNGs cannot be bundled without fetching the resources. Meta may change or remove remote URLs.
