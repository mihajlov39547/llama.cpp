Set up Local Prompt Enhancer

Improve your prompts with local AI. This extension currently works with the ChatGPT composer at chatgpt.com.

1. Get llama.cpp and a model

Install or build llama.cpp for your operating system and obtain a compatible GGUF model that your hardware can run. Follow the official llama.cpp server documentation. The extension does not install software or download models.

2. Start the local server

Run the server on this same computer, bound to 127.0.0.1:8080. Replace the example model path with your own. Use the executable path for your installation if it is not on PATH.

macOS / Linux terminal

llama-server -m "/path/to/model.gguf" --host 127.0.0.1 --port 8080

Windows PowerShell (from the executable's directory)

.\llama-server.exe -m "C:\models\model.gguf" --host 127.0.0.1 --port 8080

Wait for the model to load. Keep the server running. Model speed, quality and memory requirements vary; not every model or server configuration is supported. This release does not configure authentication or other API origins.

3. Check the connection

Open http://127.0.0.1:8080/v1/models. Expect JSON with a model ID in data. You can also open the toolbar popup and select Refresh status. Connected means model discovery succeeded, not that an inference request was tested.

4. Open ChatGPT

Open ChatGPT, sign in if needed, and type a draft. Refresh an existing tab after installing or updating the extension. The Improve Prompt row appears near the composer.

5. Improve and refine

Click Improve Prompt to read and send your draft to your local server. Review the suggestion. Refine Further sends the original draft and only the latest successful rewrite for another pass; it keeps the previous preview if the request fails. Editing the draft or changing chats disables Apply and refinement for that preview. Click Improve Prompt to start again with the new draft.

6. Apply or Copy

Apply replaces the current draft if it still matches and the edit can be verified, then closes the preview. It never presses Send or submits the prompt to ChatGPT. Copy writes the suggestion to the system clipboard for you to paste manually. Copy original is available before applying; native undo may also recover the original. Cancel hides the panel and aborts the request, though the server may continue work until it notices disconnection.

Privacy and control

The extension sends prompt text only to http://127.0.0.1:8080 after your Improve Prompt or Refine Further action. The popup sends no draft text. No developer-operated prompt service, analytics or advertising trackers are used. Settings are stored locally; prompts and suggestions are held temporarily in page/worker memory and are not written to extension storage.

You control the local server, including its logs, security and any forwarding. A proxy, tunnel or server plugin could transmit data elsewhere. ChatGPT can handle text in its editor according to its own policies, including before manual submission. Clipboard contents may be available to other applications or synced by your operating system. These systems are outside the extension's control.
